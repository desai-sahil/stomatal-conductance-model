Stomatal Conductance Model

Interactive parameter dashboards for the coupled hydropassive–hydroactive (HP–HA) stomatal model.

Each dashboard runs entirely in your browser via Pyodide — no install, no server. The first load takes roughly 10–30 seconds while the scientific Python stack downloads; after that, it is cached and returns are near-instant. Every dashboard exposes five parameter groups as tabs: Hydraulics, Vstress, ABA biosynthesis, ABA signaling, and Electrophysiology.
